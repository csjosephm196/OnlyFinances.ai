# Project Rules

1. **TypeScript Strict Mode**: All frontend code must use strict type checking. No `any` types unless absolutely necessary.
2. **API Documentation**: All backend endpoints must be documented using OpenAPI/Swagger standards.
3. **Architecture**: 
   - Frontend: React + Tailwind
   - Backend: FastAPI + Python
4. **Code Style**:
   - Use functional components.
   - Use Tailwind utility classes.
